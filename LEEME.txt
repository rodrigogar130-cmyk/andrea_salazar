PARA ANDREA — UNA PÁGINA ESPECIAL DE RODRIGO

CONTENIDO
  index.html       Página principal (para GitHub Pages)
  styles.css       Diseño adaptable a celular y computadora
  script.js        Animaciones y sistema de respuestas
  assets/andrea.jpg Fotografía proporcionada

CÓMO VERLA
1. Descomprime el archivo ZIP.
2. Abre index.html en tu navegador (Chrome o Edge).
3. Desplázate hasta la sección final y prueba las cuatro respuestas.

CÓMO PUBLICARLA EN GITHUB PAGES
1. Crea un repositorio, por ejemplo "para-andrea".
2. Sube index.html, styles.css, script.js y la carpeta assets (incluido su archivo).
3. En GitHub entra a Settings > Pages.
4. En Build and deployment elige Deploy from a branch, rama main, carpeta /(root).
5. Guarda. La dirección suele ser https://TUUSUARIO.github.io/para-andrea/
   (GitHub te mostrará el enlace concreto cuando termine el despliegue).
